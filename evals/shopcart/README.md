# shopcart

Small cart and pricing library used by the shop backend.

- `npm test` runs the unit tests.
- `npm run build` writes a sample invoice to `dist/`.

## Local data

`data/` is not tracked in git.

- `data/cache/` holds generated lookup caches.
- `data/exports/` holds the quarterly order exports sent to accounting.
- `data/customers.json` is the customer list imported from the old system.
